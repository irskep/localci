## localci docs

Run this to quickly learn everything localci can do

### Synopsis

Read LocalCI's bundled narrative documentation. For command options, use localci --help or localci <command> --help. For a compact command reference, use localci docs --cheatsheet.

```
localci docs [flags]
```

### Options

```
      --cheatsheet   print a compact CLI cheatsheet
  -h, --help         help for docs
      --plain        print plain text instead of opening a man-style viewer
      --roff         print roff manpage source
```

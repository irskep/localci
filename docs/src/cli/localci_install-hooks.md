## localci install-hooks

Install the Git post-commit hook

### Synopsis

Install LocalCI's Git post-commit hook entry for a repository.

```
localci install-hooks [flags]
```

### Examples

```
localci install-hooks
localci install-hooks --repo /path/to/repo
```

### Options

```
  -h, --help          help for install-hooks
      --repo string   repo directory; defaults to nearest Git repo ancestor
```
